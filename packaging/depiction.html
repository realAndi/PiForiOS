Pi Coding Agent

The open-source agent harness, patched to run on jailbroken iOS

Pi is a coding agent that talks to whichever model provider you have an API key for — Anthropic, OpenAI, Google, Groq, OpenRouter, a local llama.cpp and around twenty more. This packages upstream's darwin-arm64 standalone build, patched so iOS will load and run it.

What gets installed

This package is about 16 KB. It does not contain Pi.

On install it downloads the official tarball from the upstream GitHub release, verifies its SHA-256, patches it on your device, signs it with ldid, runs it to confirm it works, and only then installs it. Takes about six seconds and needs a network connection.

Repository

https://reallyitsandi.com/repo/

After installing

Give it a key, then run it:

export ANTHROPIC_API_KEY=sk-ant-…  →  pi

Or run pi and use /login, which stores the key in ~/.pi/agent/auth.json. There is no keychain involved, so unlike some ports nothing has to be worked around here.

Requires

  • A rootless jailbreak (/var/jb) — tested on Dopamine
  • iOS 15 or later, arm64 — tested on iOS 17.3
  • Depends: zsh, bash, python3, ldid, curl, tar, coreutils, ripgrep, fd, uikittools — Sileo installs any that are missing. Node.js is not required.
  • ~500 MB free during install; ~81 MB after

Notes

  • Sileo is the updater. Pi's own version check is off, because for a standalone build it points at the macOS download, which cannot run here.
  • JIT is emulated: iOS has no MAP_JIT, so the shim flips the JIT pool between writable and executable with mprotect. The wrapper sets BUN_JSC_useConcurrentJIT=0, which this requires.
  • JavaScriptCore's gigacage is off. It reserves 64 GB of address space and iOS refuses anything over 4 GB, so the process would not start.
  • Search uses the packaged ripgrep and fd. If Pi ever downloaded its own copies on another platform, the wrapper removes the ones that cannot run here.
  • Clipboard and modifier-key helpers are inert — they need AppKit.
